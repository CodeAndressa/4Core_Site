Manual do Sistema 4Core

Guia técnico definitivo para desenvolvedores e equipe de operações.

1. Visão Geral

O sistema 4Core é uma plataforma de geração de leads e gestão comercial integrada, desenhada para atuar como o portal principal de uma consultoria especializada em controle de ponto e acesso.

Lead Gen

Foco total em converter visitantes em oportunidades de negócio.

SDR Automático

Chatbot com IA que qualifica e captura leads 24/7.

BI Integrado

Análise de tráfego e conversão em tempo real.

Conexão: O usuário entra pelo institucional → Faz o diagnóstico ou usa o chatbot (Ambos validam interesse) → Os dados são sincronizados no Supabase → O admin gerencia os resultados no Dashboard de BI.

2. Arquitetura

O projeto utiliza o Next.js (App Router) como fundação, separando claramente as responsabilidades.

Estrutura principal:

  • /src/app: Rotas, páginas e layouts.
  • /src/app/api: Endpoints de backend (Next API Routes).
  • /src/lib/services: Lógica de negócio e integração com Supabase.
  • /src/components: UI modularizada (Sections, Forms, Admin).
Fluxo de Dados: O frontend chama API Routes → API Routes usam Services → Services consultam Supabase/Groq.

4. Funcionalidades Detalhadas

Localizado em: src/components/sections/DiagnosticSection.tsx

🤖 Chatbot SDR (Sales Dev Representative)

Chat interativo com IA que tira dúvidas técnicas sobre Portaria 671 e qualifica o lead perguntando o tamanho da empresa e o modelo de trabalho.

📊 BI / Analytics Dashboard

Área administrativa protegida para monitorar ROI, cliques no WhatsApp e taxa de conversão por página.

Rota: /admin/dashboard

5. Fluxos do Sistema

Fluxo Principal (Caminho Feliz):
  1. Visitante entra na Home atraído pela promessa de conformidade.
  2. Identifica um risco na seção de "Risco Trabalhista".
  3. Clica em "Fazer Diagnóstico Único".
  4. Responde 5 perguntas → Vê resultado crítico.
  5. Preenche nome/email/tel para receber relatório completo.
  6. Ação Interna: O lead cai na tabela do Supabase e o comercial recebe um e-mail em tempo real.

6. CRM (Supabase)

Os dados são armazenados de forma estruturada no PostgreSQL do Supabase.

Tabela: leads

CampoTipoDescrição
iduuid (PK)Identificador único
nametextNome completo do lead
emailtextEmail de contato
phonetextTelefone com DDD
statustextStatus (novo, contatado, qualificado)
source_pagetextPágina onde converteu

Políticas de RLS: A tabela `leads` permite inserção pública (para anonimous) mas leitura apenas para o role `service_role` (nosso backend).

7. Sistema de Eventos

O rastreamento de eventos é feito através da biblioteca trackEvent.ts.

// Exemplo de uso
trackEvent({
  type: 'whatsapp_click',
  page: '/solucoes/controle-de-jornada',
  source: 'floating_button'
});

Uso no BI: Esses eventos são agregados pelo AnalyticsService para gerar gráficos de barras e cálculos de Bounce Rate no dashboard.

8. Chatbot com IA

O chatbot utiliza a Base de Conhecimento localizada em src/lib/knowledgeBase.ts como fonte de verdade.

Lógica de Decisão:

  • Detecta intenção via keywords (comprar, dúvida, preço).
  • Calcula Score de Qualificação (0-100) com base no tamanho da empresa.
  • Troca de papéis: Começa como informador e termina como capturador de dados.

9. APIs do Sistema

POST /api/lead

Cria um lead diretamente. Requer name, email e phone.

Req: { name: string, email: string, phone: string, source_page: string } Res: { success: boolean, data: Lead }
POST /api/events

Captura interação do usuário.

Req: { type: string, page: string, session_id: string }

10. Campos Importantes

Ao analisar dados no Supabase, atente-se a:

  • qualification_score (tabela chatbot_leads): Define se o comercial deve ligar em 5 min ou 24h.
  • session_id (tabela events): Permite reconstruir a jornada do usuário no site (funil).
  • employees: Faixa de tamanho da empresa para precificação correta.

11. Como Expandir o Sistema

Adicionar novo Evento:

  1. Localize src/types/analytics.ts e adicione o tipo no enum EventType.
  2. Crie um helper em src/lib/tracking/trackEvent.ts.
  3. Chame o helper no componente desejado.

Adicionar Nova Solução/Produto:

  1. Adicione os dados estáticos em src/data/products.ts para o site.
  2. Adicione o contexto no knowledgeBase.ts para o chatbot aprender sobre ele.

12. Boas Práticas

Regra de Ouro: Nunca faça queries diretas ao Supabase nos componentes. Use sempre a camada de Services.
  • Tipagem: Sempre defina interfaces em src/types/ antes de implementar.
  • Validação: Use o contactFormSchema (Zod) para qualquer novo formulário.
  • Contexto: Sempre mantenha o CLAUDE_CONTEXT.md atualizado após grandes mudanças arquiteturais.

13. Guia Rápido (Uso Prático)

Como ver leads?

Acesse o Dashboard Administrativo via /admin/dashboard ou direto no painel do Supabase na tabela leads.

Como simular o bot?

Abra o site, clique no ícone de chat e diga "Dúvida sobre Portaria 671" para ver a filtragem da IA.

Como testar track?

No console do navegador: localStorage.getItem('4core_session_id') deve mostrar seu ID de tracking.
